# Learn Polish Dates (first version)

> **Archived.** This is an earlier version, kept for reference. The current app is **Say the Date in Polish**: [repo](https://github.com/newbroman/too-obvious) · [live app](https://newbroman.github.io/too-obvious/). The numbers, dates and clock trainers are also combined in [Polska](https://github.com/newbroman/Polska).

The first version of the Polish date trainer: says the day, date, month and year in Polish, phonetics and English, with a Sunday-first Polish calendar, holidays (including Easter) and a cultural page.

**Live (frozen) app:** https://newbroman.github.io/Polishdates/

## Files

A static web app with no build step: `app.js`, `cultural.js`, `holiday.js`, `index.html`, `manifest.json`, `phonetics.js`, `script.js`, `sw.js`, `year.js`, `years.js`.

To run it locally: `python3 -m http.server`, then open http://localhost:8000.
